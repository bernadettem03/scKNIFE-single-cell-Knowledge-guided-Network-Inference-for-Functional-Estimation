Figure_S6.ipynb is the plotting-only companion to main Figure 6. It regenerates SA, SB, SJ, S1, SFUNNEL, SDIRECTION, SU3 and S2 plus the compiled 297 × 570 mm vector page.

The panels cover metastatic-status overlap and enrichment, GPR-GPA/direct-scKNIFE concordance, patient-level concordance robustness, the Tier-3 filtering cascade, the homocysteine direction screen, the exploratory single-patient Bx–Surgery–Recurrence audit, and the cross-platform 2-aminoethylphosphonate status candidate. Statistical derivations are maintained under Figure_6/analysis/; the plotting notebook consumes frozen checksummed tables only.

Rendering uses the established Matplotlib fallback in the Python 3.9 `bgnmf` environment; current `cnsplots` releases require Python 3.10 or newer and were not installed or substituted.
