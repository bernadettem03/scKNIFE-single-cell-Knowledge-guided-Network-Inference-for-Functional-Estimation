# Active Supplementary Figure S6 inputs

The five files in `manifest.json` are the complete active inputs for S6A–E. A and B use the 33-pathway metastatic-status mapping and LC–MS enrichment tables. C–E join the frozen Figure 4 UMAP to the Figure 4 Wu SingleR major calls by exact cell ID, then overlay inferred L-carnitine, L-octanoylcarnitine and octanoyl-CoA scores for 6,014 paired biopsy/surgery Myeloid cells. Patient-level tests and summary statistics are in the main Figure 6 data package and Supplemental Tables 6C–G.
